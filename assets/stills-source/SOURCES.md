# Stills: raw sources

Raw frames for the stills pipeline (`scripts/stills.mjs`). They are not graded, cropped or resized here. The film file stays the preferred source (spec §7, decision 1). These are interim frames, pulled from public fan projects on GitHub.

Credit: « La Classe Américaine — Le Grand Détournement (1993). © Warner Bros., Canal+. »

Timecodes are the nearest line in Sam Hocevar's French subtitle file (github.com/veloce/Project_Abitbol, `American_class.fr.srt`). They are approximate and tied to that rip, so check each one against the film file before using it in `stills.ts`.
